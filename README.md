# Machine Learning for Smart Campus Management at SRMIST

Assignment project applying regression, classification and clustering to campus problems.

## Models
| File | Task | Algorithm |
|---|---|---|
| canteen_waiting_time_regression.py | Predict canteen waiting time | Linear Regression |
| waste_classification_model.py | Classify waste as Organic, Recyclable or General | Decision Tree |
| transport_clustering.py | Group students by transport pattern | K-Means |

## How to run
pip install pandas matplotlib scikit-learn
python canteen_waiting_time_regression.py

The datasets are small sample datasets created inside each script.
